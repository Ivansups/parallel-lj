## Context

Исходные материалы: два планировочных артефакта (план расчёта и план доклада). Модель: N частиц в кубической периодической ячейке, потенциал LJ с обрезкой rc = 2,5σ, приведённые единицы, ρ* = 0,8442, T* = 0,722, Δt* = 0,005, скоростная схема Верле. Дедлайны: внутренний 12 ноября 2026, официальный срок статьи 16 ноября, семинар 27–28 ноября. Сегодня 16 октября, то есть около 27 дней. Лимиты кластера и регламент доклада неизвестны.

## Goals / Non-Goals

**Goals:**
- Корректная физика (сверка с последовательным кодом и литературой) и понятные результаты масштабирования.
- Результаты в порядке код → речь → слайды; каждая цифра в речи, слайдах и статье прослеживается до одной таблицы результатов.

**Non-Goals:**
- GPU, гибрид MPI+OpenMP, балансировка нагрузки для неоднородных систем, другие потенциалы.
- Продакшн-возможности МД (тонкая настройка списков соседей сверх Verlet skin, дальнодействующие поправки сверх простой хвостовой).

## Decisions

- **Язык: C++17 + MPI** для симуляции; **Python** (numpy, matplotlib, pytest) для анализа и графиков. Причина: стандарт для кластеров, совпадает с планом. Альтернатива: Fortran или Python+numba — отклонены из-за доступности MPI и риска по скорости. Предварительно, до проверки кластера (открытый вопрос).
- **Сначала последовательная версия как эталон.** MPI-код обязан воспроизводить энергии последовательной версии (с точностью до округления) на одном и том же начальном состоянии при малом N. Причина: отделяем физические ошибки от параллельных.
- **Пространственная декомпозиция на 3D-сетке процессов** (`MPI_Cart_create`), ширина гало = rc + skin, cell lists с пересборкой списков раз в несколько шагов. Альтернатива: декомпозиция по частицам — отклонена из-за плохого масштабирования.
- **Сдвинутый потенциал LJ** (U(r) − U(rc), rc = 2,5σ): энергия непрерывна на обрезке. Обычная обрезка давала дрейф 1,5·10⁻³ независимо от dt (проверено при dt = 0,005…0,00125); со сдвигом 9,4·10⁻⁵. Результаты (давление, энергия) отличаются от опубликованных для полного LJ; при сверке нужна поправка на обрезку или сравнение с данными для усечённого сдвинутого LJ.
- **Фиксированные seed и начальная решётка** (FCC, максвелловские скорости): запуски воспроизводимы и сравнимы между разными p.
- **Железо неизвестно:** считаем на том, что реально доступно (локальные ядра, затем кластер, если появится). Диапазон p и N определяется железом и честно указывается в статье. Данные не выдумываются и не экстраполируются без пометки; допустима только модель масштабирования, явно названная моделью.
- **Доклад 5–7 минут:** около 6 минут, 7–8 слайдов, только главное.
- **Замеры:** `MPI_Wtime` только вокруг основного цикла, медиана из 3 запусков, максимум по рангам.
- **Единая таблица результатов** (`results/scaling.csv`) — источник для графиков, речи, слайдов и статьи, чтобы цифры не расходились.
- **Документы:** речь на русском в `docs/speech.md` с отметками времени по разделам; слайды делаются после стабилизации речи, один блок слайдов на раздел речи.
- **TDD** по правилам проекта: сначала тесты для интегратора, силового ядра, cell lists, обмена гало (сравнение serial и MPI), скриптов анализа.

## Risks / Trade-offs

- [Доступ к кластеру/очереди] → Запросить доступ на первой неделе; запасной вариант — честные результаты на локальных ядрах (например p = 1…8 или сколько есть), с указанием ограничений в статье.
- [Ошибки MPI съедают срок] → Последовательный эталон и сравнение на малом N; обмен гало разрабатывать поэтапно.
- [Запуски масштабирования падают поздно] → Короткие пробные запуски при p = 1, 8 до основной серии; серию начать не позднее 30 октября.
- [Плохое масштабирование при больших p] → Всё равно публикуем и анализируем (отношение гало/вычислений), не скрываем. Формулировки в речи пишутся после результатов.
- [Речь и слайды написаны до финальных цифр] → Речь начинается только после заморозки таблицы результатов (5 ноября); наброски структуры допустимы раньше.
- [Статья не входит в указанный порядок] → Черновик статьи идёт параллельно с речью с 5 ноября; отправка остаётся на 16 ноября.
