## ADDED Requirements

### Requirement: Serial LJ simulation
Система SHALL предоставлять последовательную программу молекулярной динамики для N частиц в кубической периодической ячейке с обрезанным потенциалом Леннарда–Джонса (rc = 2,5σ) в приведённых единицах, с интегрированием скоростной схемой Верле.

#### Scenario: Reference state point
- **WHEN** программа запускается с ρ* = 0,8442, T* = 0,722, Δt* = 0,005
- **THEN** она стартует с решётки FCC и максвелловских скоростей с фиксированным seed и выдаёт термодинамические величины каждые 10 шагов

#### Scenario: Energy conservation in NVE
- **WHEN** NVE-расчёт завершён после уравновешивания
- **THEN** относительный дрейф полной энергии ниже порога, заданного в тестах (изначально 1e-4 за расчёт)

### Requirement: Physical validation
Система SHALL вычислять E(t), g(r), давление P и коэффициент диффузии D (по наклону MSD) и сравнивать их с литературой при тех же ρ*, T*.

#### Scenario: NIST benchmark
- **WHEN** код запущен в условиях эталонных NVE-расчётов NIST (N = 500, rc = 3σ, dt = 0,005, T* ≈ 0,85, ρ* = 0,84) с обычной обрезкой и стандартными дальними поправками
- **THEN** U*, p* и D* согласуются с таблицей NIST (U* = −5,909, p* = 0,910, D* = 0,042) в пределах задокументированного допуска

#### Scenario: Radial distribution function
- **WHEN** g(r) вычислена
- **THEN** для идеального газа g ≈ 1, для решётки FCC координационное число первой оболочки равно 12, для жидкости g → 1 на больших r

#### Scenario: Working state point
- **WHEN** выполнен расчёт при ρ* = 0,8442, T* = 0,722, rc = 2,5σ
- **THEN** P, U и D приведены со статистической погрешностью; сравнение с литературой делается только для проверяемых источников

### Requirement: MPI parallel version
Система SHALL предоставлять MPI-версию с пространственной декомпозицией по 3D-сетке процессов, обменом граничными частицами в пределах rc плюс skin, cell lists и `MPI_Allreduce` для глобальных величин.

#### Scenario: Agreement with serial version
- **WHEN** MPI-версия запускается на малом N при p = 1, 2, 4, 8 из того же начального состояния
- **THEN** энергии совпадают с последовательной версией с точностью до округления на первых шагах

#### Scenario: Particle migration
- **WHEN** частица пересекает границу подобласти
- **THEN** она передаётся процессу-владельцу, а общее число частиц не меняется

### Requirement: Reproducibility
Система SHALL использовать фиксированные seed и документированную процедуру сборки и запуска.

#### Scenario: Repeat run
- **WHEN** один и тот же вход запускается дважды при одном p
- **THEN** термодинамический вывод одинаков с точностью до задокументированных отличий порядка редукции
