## ADDED Requirements

### Requirement: Strong scaling experiment
Система SHALL измерять сильное масштабирование при фиксированном N и ряде p, ограниченном реально доступным железом (ядра ноутбука/сервера или кластера, если доступ появится), вычисляя S(p) = T(1)/T(p) и E(p) = S(p)/p.

#### Scenario: Complete strong-scaling table
- **WHEN** серия запусков завершена
- **THEN** `results/scaling.csv` содержит T(p), S(p), E(p) только для реально выполненных запусков, каждое значение — медиана из 3 запусков, с указанием железа

### Requirement: Weak scaling experiment
Система SHALL измерять слабое масштабирование при 5000 частиц на процесс, N растёт пропорционально p.

#### Scenario: Weak-scaling table
- **WHEN** серия запусков завершена
- **THEN** таблица содержит время шага для каждого p, медиана из 3 запусков

### Requirement: Timing methodology
Замер времени SHALL охватывать только стадию расчёта, без инициализации и вывода, и использовать максимум времени по рангам.

#### Scenario: Timer placement
- **WHEN** запуск завершён
- **THEN** сообщённое время не включает подготовку и запись файлов

### Requirement: Job automation
Система SHALL предоставлять скрипты заданий для планировщика, которые выполняют всю серию и сохраняют сырые логи.

#### Scenario: Reproducible campaign
- **WHEN** скрипт задания отправлен в очередь
- **THEN** он выполняет все точки по 3 раза и записывает сырые логи и сводный CSV

### Requirement: Plots and tables
Система SHALL строить графики S(p), E(p), слабого масштабирования и таблицу времён из CSV одним скриптом.

#### Scenario: Regenerate figures
- **WHEN** скрипт графиков запускается на `results/scaling.csv`
- **THEN** рисунки и таблицы детерминированно записываются в `figures/`
