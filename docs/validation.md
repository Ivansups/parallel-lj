Все числа получены командами из репозитория (см. «Как воспроизвести»). Единицы приведённые: σ = ε = m = 1.

Потенциал в динамике усечён и сдвинут (U(r) − U(rc)): без сдвига дрейф энергии был 1,5·10⁻³ независимо от шага, со сдвигом 9,4·10⁻⁵. Силы при этом такие же, как у обычной обрезки. Для сравнения с литературой энергия пересчитывается к обычной обрезке (`plain_potential`) и дополняется стандартной дальней поправкой.

## Сравнение с эталоном NIST

Эталон: [NIST, NVE MD для жидкости LJ](https://mmlapps.nist.gov/srs/LJ_PURE/md.htm): N = 500, rc = 3σ, dt = 0,005, T* ≈ 0,85, обычная обрезка + стандартные дальние поправки, давление по вириалу.

У нас 8 независимых прогонов на плотность (уравновешивание Берендсена 50 t*, затем 100 t* NVE). Температура NVE зависит от прогона (0,83–0,86), поэтому значения приведены к температуре NIST линейной подгонкой по прогонам; погрешность — стандартная ошибка подгонки.

| ρ* | величина | наш результат | NIST | разница |
|---|---|---|---|---|
| 0,776 | U | −5,5100 ± 0,0006 | −5,517 | +0,0070 |
| 0,776 | P | 0,0084 ± 0,0023 | 0,030 | −0,0216 |
| 0,776 | D | 0,0636 ± 0,0010 | 0,061 | +0,0026 |
| 0,82 | U | −5,7921 ± 0,0002 | −5,803 | +0,0109 |
| 0,82 | P | 0,5613 ± 0,0023 | 0,573 | −0,0117 |
| 0,82 | D | 0,0489 ± 0,0004 | 0,048 | +0,0009 |
| 0,84 | U | −5,9133 ± 0,0008 | −5,909 | −0,0043 |
| 0,84 | P | 0,8856 ± 0,0038 | 0,910 | −0,0244 |
| 0,84 | D | 0,0418 ± 0,0013 | 0,042 | −0,0002 |

Выводы:
- **D** согласуется с NIST в пределах 4 % (на двух плотностях в пределах ошибки).
- **U** согласуется в пределах 0,2 %; знак разницы меняется с плотностью, а на ρ* = 0,84 точка NIST выбивается из гладкого хода по плотности, что похоже на шум одиночного эталонного прогона.
- **P** на всех трёх плотностях ниже эталона на 0,01–0,03 (2–4 %, 2–4σ). **Причина не установлена.** Проверено и исключено: недостаточное уравновешивание (4-кратно более долгое дало те же значения), разное число степеней свободы в T объясняет не более половины. Не проверено: конкретная формула вириального давления в эталоне. В статье это нужно указывать как остаточное расхождение, а не как согласие в пределах ошибки.
- ρ* = 0,90 не использован: при T = 0,85 система, стартуя с решётки FCC, остаётся кристаллом (D ≈ 10⁻⁴), а эталон — жидкость.

## Открытые пункты

- **Давление ниже эталона NIST на 2–4 %** на всех проверенных плотностях (см. выше). Причина не найдена; кандидаты: определение вириального давления в эталоне, определение T (3N или 3N−3 степеней свободы). Решение отложено, чтобы не задерживать MPI-часть; в статье писать как остаточное расхождение.

## Как воспроизвести

```bash
docker build -t parallel-lj .
docker run --rm -v "$PWD":/work parallel-lj bash -c 'cmake -S . -B build && cmake --build build && ctest --test-dir build'
.venv/bin/python -m pytest -q tests_py
docker run --rm -v "$PWD":/work parallel-lj scripts/run_nist.sh
docker run --rm -v "$PWD":/work parallel-lj scripts/run_working.sh
.venv/bin/python analysis/compare_nist.py
.venv/bin/python analysis/plot_rdf.py
```
