# parallel-lj
# Parallel Molecular Dynamics of a Lennard-Jones Fluid  Параллельная молекулярная динамика системы Леннарда–Джонса на MPI. Две задачи: **доказать, что физика считается правильно**, и **показать, что код быстро работает на большом числе ядер**.  ## Что внутри  Модель — классический LJ-флюид в кубической ячейке с периодическими границами, обрезанный потенциал (rc = 2.5σ), интегрирование схемой Верле в скоростной форме. Приведённые единицы, рабочая точка жидкого состояния: ρ* = 0.8442, T* = 0.722, Δt* = 0.005.  Параллелизация — пространственная декомпозиция по процессам MPI с обменом граничными частицами (halo exchange) и cell lists. Глобальные величины собираются через `MPI_Allreduce`.  ## Что проверяем  | Величина | Зачем | Как проверяем | |---|---|---| | Полная энергия `E(t)` | Корректность интегратора | Дрейф в NVE должен быть мал | | Радиальная функция `g(r)` | Структура жидкости | Сверка с литературой при тех же ρ*, T* | | Давление `P` | Термодинамика | Сравнение с EOS LJ-жидкости | | Коэф. диффузии `D` | Динамика | Наклон MSD | | Время шага `t_step` | Производительность | Медиана из 3 запусков |  ## Масштабируемость  - **Strong scaling:** N ≈ 2·10⁵ фиксировано, p = 1…128.   Считаем ускорение `S(p) = T(1)/T(p)` и эффективность `E(p) = S(p)/p`. - **Weak scaling:** 5000 частиц на процесс, N растёт линейно с p.   Идеал — время шага почти не меняется.  Замеры — только на стадии расчёта, без инициализации и записи. Каждая точка — медиана трёх прогонов.  ## Стек  `C / C++ / Fortran` + `MPI`.
