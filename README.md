# parallel-lj

Параллельная молекулярная динамика жидкости Леннарда–Джонса на C++17 и MPI.

Проект решает две задачи: показать, что код **считает физику правильно**, и что он **ускоряется при росте числа процессов**.

## Модель

- N частиц в кубической ячейке с периодическими границами, приведённые единицы (σ = ε = m = 1).
- Потенциал Леннарда–Джонса, усечённый и сдвинутый на rc = 2,5σ.
- Интегрирование скоростной схемой Верле.
- Рабочая точка жидкости: ρ* = 0,8442, T* = 0,722, Δt* = 0,005.
- Старт с решётки FCC, максвелловские скорости, фиксированный seed.

## Что умеет

- Последовательная версия: списки соседей на основе ячеек (cell lists) с запасом skin, термостат Берендсена, давление через вириал, дальние поправки.
- Наблюдаемые: энергия, температура, давление, радиальная функция g(r), среднеквадратичное смещение и коэффициент диффузии.
- MPI-версия: пространственная декомпозиция на 3D-сетке процессов, перенос частиц между подобластями, обмен граничными частицами (halo), локальные cell lists, глобальный термостат.
- Анализ на Python: подгонка коэффициента диффузии, блочные ошибки, сравнение с эталоном NIST.

## Проверка

- MPI-версия воспроизводит энергию, вириал, силы и траекторию последовательной версии при 1, 2, 4 и 8 процессах.
- Силы, сохранение энергии, cell lists, термодинамика и наблюдаемые покрыты автоматическими тестами.
- Результаты сравниваются с эталоном NIST, подробности в [docs/validation.md](docs/validation.md).

## Масштабируемость

- Сильное масштабирование: фиксированное N, растёт число процессов p; ускорение S(p) = T(1)/T(p), эффективность E(p) = S(p)/p.
- Слабое масштабирование: фиксированное число частиц на процесс, N растёт вместе с p.
- Время измеряется только вокруг основного цикла расчёта, берётся максимум по процессам.

## Сборка и запуск

Нужны CMake, компилятор C++17 и MPI (проще всего через Docker-образ из репозитория).

```bash
docker build -t parallel-lj .
docker run --rm -v "$PWD":/work parallel-lj bash -c 'cmake -S . -B build && cmake --build build && ctest --test-dir build'
```

Тесты анализа:

```bash
python -m pytest -q tests_py
```
